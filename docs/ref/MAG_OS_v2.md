# Mag OS v2 — usable operating layer (ARK-shaped, Mag-native)

**Version:** 2.0.0  
**Commitment:** `mag-os-v2-001`  
**Activation:** dashboard loads this automatically; phrase **"Activate Mag OS v2"** for LLM paste.

## What this is

A thin **governance + surface** layer for Mag — inspired by ARK Civic's card / gates / provenance / Phoenix, remapped to:

- residual DNA (cold)  
- presented corpus (mirror)  
- seats / pack / trail (prices)  
- smoke / compose (self-check)

**Not** civic cosplay. **Not** more Advanced tabs.

## Root law (self-applying)

1. Residual is DNA; UI is viewport.  
2. Corpus **as presented**, not model-interpreted (`MIRROR_PRESENTED.md`).  
3. Pack-first remotes; T0/T1 never remote.  
4. Seat purity while a run is open.  
5. Process (playbook) ≠ case (residual) ≠ mid-goal (trail).  
6. Specialist scarce: hard judgment + pack only.  
7. Metrics on the surface: smoke · compose · open run · corpus flag.
