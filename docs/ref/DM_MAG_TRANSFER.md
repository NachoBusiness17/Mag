# DM ↔ Mag transfer map

**Commitment:** `dm-mag-transfer-001`  
**Why:** You are a DM. Table is the flight simulator for the harness — learn to **utilize and exploit** Mag, and FILE multi-seat data.

## At-table → Mag seat

| You do (DM/player) | Mag fires | Exploit later |
|--------------------|-----------|---------------|
| Declare a clear move | Engine Fast (code) | Clear tickets → local/dispatch |
| Improv nonsense | Curveball tables / gen | Freestyle → structured FILE |
| “What should we do?” | Salon → DeepSeek guest | Pack then scarce remote |
| “Take A” / rule it | Confirm L3 | Approve merges / apply |
| Look / rumor / drink | Local-only turn | Don’t burn Grok on scut |
| Seal session | residual-style card + events | SessionEnd habit |
| Return to tavern | Hub cool-down | context-pack / working.md |

## Fast / Slow (DM language)

- **Fast:** map, HP, dice, legal chips, tables, short passage  
- **Slow:** guest advice, structure, hard judgment  
- **You:** chair — confirm before the world rewrites  

Constrained local on a **codebase** = adjudicating only what the **sheet and map** allow. Same win.

## Primer hour (skill drill)

1. `/table` → New watch → classic one (tavern) → character  
2. 5 turns **without** “what should I do” (feel Fast path)  
3. One **what should I do** → take A (feel Slow + confirm)  
4. Freestyle folly + leave for the road  
5. Say **seal session** or use Seal control  
6. Check: can you name which seat fired each time?

## Data harvest

Session seal → `memory/working/game_sessions/`.
