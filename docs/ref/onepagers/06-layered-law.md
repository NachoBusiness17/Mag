## Don’t choose

| Bad | Why |
|-----|-----|
| One “good agent” writes all rules | Stale, overfits, becomes prompt bloat |
| Pure emergence only | Needs episodes; replans 2000× before “learning” |

## Do: velocity layers

```text
L5 Constitution     CONSTITUTION.md · T0–T3 tiers
L4 Hard rails       constitutional_rails.json → mag/rails.py (NO LLM, tool block)
L3 Frozen spec      BUILD file · caveman · factory phase gate
L2 Case law         decisions_log · FKB · training_patterns
L1 Skills/weaves    ponytail · patch-verify · IJL beads
L0 Reflexes         collapse · dedupe · loop-audit pause
```

## Who writes what

| Layer | Writer |
|-------|--------|
| Rails | Human + rare promote |
| RUN/BUILD | Operator freeze |
| Remedies / patterns | **Emergent** from episodes → **draft** |
| Skills | Mined from successful runs → promote |
| Constitution | Saturday sign |

**Good agent role:** draft improve candidate or RUN amendment — **never** silent L5.

## Outcome gates > prose

- One leaf per job  
- Phase lock (plan ≠ queued build)  
- Rails block DNA/secret writes  
- Reflex: duplicate refuse, plan theater pause  
- Audit exit: ponytail/caveman before “done”  

## Emergence path

```text
episode → training_patterns / FKB → improve candidate → promote → weave or rail
```

Example: 18× patch loops → **patch-verify weave** (filed, not dictated).
