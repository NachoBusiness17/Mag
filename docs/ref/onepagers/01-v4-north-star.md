# One-pager: Mag v4 north star

**Commitment:** `mag-v4-north-001` · Planning only

## One breath

Mag v4 is the **mold**: process, eval, and patterns **before** substrate volume. v3 naming in git = infrastructure (orchestrator, seats, pack, Office), not a checklist to finish first.

## North star

> **Reflexes with trails · episodes with join keys · promote for law.**

- **Auto-handle** = typed actions (pause, dedupe, batch, defer, escalate) — not smarter prompts  
- **Learn** = scored episodes → improve candidate → human `promote --apply`  
- **Never** silent router/skills/rails mutation  

## L1 → L5 ladder

| Layer | What | Example |
|-------|------|---------|
| L1 file | Observation on disk | trail, event, knot, FKB sig |
| L2 score | Pattern + severity | loop-audit, training_patterns |
| L3 promote | Human signs change | configs, RUN row, rails |
| L4 habit | Repeated success | skill weave, spider rule |
| L5 constitution | Stable law | CONSTITUTION.md, tiers |

## Four questions (anti-bloat gate)

1. Which **pattern** (`training_patterns.yaml`)?  
2. Which **eval case**?  
3. Which **join keys** (`queue_id`, `session_id`, …)?  
4. **Auto / draft / human**?

Blank → defer.

## Build order (when coding)

1. `training_patterns.yaml` + eval JSON  
2. `loop_outcome` events + conductor `pause_fill`  
3. Pack `mode` + job-aware skills  
4. `task_estimate` + `cost_ledger`  
5. `[steward]` jobs + actor memory schema  

## Non-goals

Auto-promote · chat-as-memory · raw T0/T1 train export · hijack Cursor billing
