# Republic launch — Mag as entry point

**For:** anyone cloning Mag before they have personal day beads.

## Two houses

| House | Repo | Job |
|-------|------|-----|
| **Mag** (private) | `local_sovereign_agent` | Your office: dashboard, beads, trails, agent cage |
| **Mycelial Republic** (public) | `mycelial-republic` | Constitution, practice data, self-tests, forkable ethics |

Private memory never commits to the republic repo. Same rules both places: no king, presented-not-interpreted, human seals irreversible acts.

## Fresh clone — what you get

**Ships (framework):**
- `memory/operator_directives.md` — autonomy contract in every context pack
- `memory/handoff/ACTIVATION.md` — paste into any AI seat
- `memory/improve/SEATS.md` — L0 janitor → L3 human matrix
- Story tab — full thesis + two-houses bridge (code-built, not your beads)
- Dashboard, chat, agent backend, orchestrator — core ops

**Empty until you work (personal soil):**
- Day beads / biography residuals
- Diary timeline
- Ideas board (unless you import)
- Pulse events from your sessions

That is correct — you are not loading Nacho's beads. You are loading the **framework** everyone will fork.

## Start here

```powershell
# Container (recommended)
powershell -ExecutionPolicy Bypass -File scripts\install.ps1 -Shortcuts

# Inside cage
scripts\mag_exec.ps1 context-pack
scripts\mag_exec.ps1 multi-smoke
```

Open **Story** in the dashboard for the full arc. Open **Office** launch pad when beads are empty.

## Add Mycelial Republic (sibling)

```powershell
cd ..
git clone <your-mycelial-republic-url> mycelial-republic
```

Optional env: `MAG_REPUBLIC_ROOT=/path/to/mycelial-republic`

Mag autopilot reports republic soil readiness (archive, train rows) without uploading private notes.
